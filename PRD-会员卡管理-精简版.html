先读这几条（贯穿全文）

  1. 新系统用 权益组合（面值 / 项目 / 产品 / 折扣）建卡，不再选「五种卡类型」；整套取代旧会员卡系统。
  2. 创建固定 三步：基本信息 → 权益组合 → 用卡策略；Step2 至少开启并配置一类权益。
  3. 当前有效持卡数 > 0 时模板 不可编辑（可复制建卡、可下架、可经结账办卡/退卡/延期）。
  4. 已下架不可新办；已持卡仍可退卡/延期；可重新上架或复制建卡。
  5. 会员卡分组：列表筛选、分组管理、编辑成员、快速分组；一卡可多组。
  6. 办卡：选择会员 Sheet 单选一位未持卡会员 → 「去结账」 → 确认办卡（会员/卡锁定；应付默认可改；办卡日期可改；服务员工必选 ≥1；是否选工位取决于业绩设置·办卡业绩：按工位分配则每人必选工位，平均分配则不要求）→ 开单记账完成支付 → 支付成功回调后写持卡与办卡业绩 → 办卡成功（来自结账时底栏可为「返回开单」）。演示种子默认办卡业绩为 按工位分配。
  7. 退卡为 整卡退；建议退款可按策略计算，实际退款金额可改后确认；本期 仅结束持卡 + 记实退，不走支付退款通道。
  8. 用卡策略两轨独立；公式随卡型（组合 / 纯折扣 / 不限次）变化；均值分母为面值 + 有限次项目权重 + 产品数量权重。
  9. 输入边界（完整稿 5.5）：卡名 ≤30；金额 0～999,999.99（元）；有效期日/月/年上限 3650/120/10；次数/产品数量 0～999。
  10. 开单支付交接与金额单位已定稿（完整稿 §7.7 / §7.8）；其余路径名标 【待联调确认】 处不臆造现网 URL。
  11. 旧入口本期全量替换（完整稿 §1.6）：工作台「卡管理」/会员卡管理/顾客详情/开单办卡/旧卡搜索/认领·AI 录卡一律切新体系。
  12. 延期：纯面值或模板永久仍显示延期入口，点按 toast「该卡永久有效，无需延期」；有期限含折扣展示参考费用，收费须支付成功后再写。
  13. 项目权益 = 独立计次 / 关联计次 双模式：Step2 四类权益 Switch 默认全部关闭，打开「项目」开关默认进入 独立计次（只设次数，适用范围 = 会员卡名称（只读不可改） + 次数；保存后名义项目 = 卡名、不进价目表；办卡后开单出浅金扣次券一键扣次（单价 = 实付 ÷ 总次数））。互斥规则：独立计次卡只能有「独立计次」一种权益且只有一个次数池——其他权益（面值/产品/折扣）已开时禁止切独立计次（toast 提示先关闭）；独立计次模式下其他三个 Switch 置灰禁用；打开项目 Switch 时若有其他权益已开 → 默认关联计次；保存/下一步防御性强制关闭非法组合。关联计次 = 普通项目权益（每项/共计），无已保存项时切换即自动展开适用项选择页（同产品/折扣开关）。
  14. 公式与本期任务：见本文模块 4–5；全量公式与任务包见完整稿 §8 / §13。

模块 1　背景 / 目标 / 范围 / 能力映射

读者：前端 ✓ · 后端 ✓ · 测试 ✓

1.1 背景

原先的会员卡系统将卡划分为 5 种固定类型，每种类型套用 预设模板字段。商户创建会员卡时：

  • 只能在类型预设内填字段，自由度不足；
  • 每次都要面对 繁复的设置页 逐项填充，创建成本高。

本期交付的「会员卡管理」将 整套取代 上述旧系统（非长期并行两套产品线），对字段按能力重新解构。

1.2 目标

目标 说明
取代旧系统 新建模与流程成为唯一建卡体系
能力覆盖 可配置出与旧五类 功能等价 的卡，也可配置旧体系 无法做出 的组合卡
创建更简 三步完成：基本信息 → 权益组合 → 用卡策略
运营闭环 列表 / 分组 / 详情 / 上下架 / 复制 / 办卡 / 延期 / 整卡退卡
策略可配置 退卡消耗与员工业绩规则在建卡时选定并随模板保存

1.3 本期做（In）

  • 会员卡模板：创建、编辑（无持卡时）、复制建卡、在售/已下架列表与详情
  • 会员卡分组：自定义分组（名称 ≤20 字、不可重名）；列表筛选轨（全部 + 分组 + 齿轮进管理）；分组管理（拖排序 / 新建 / 重命名 / 删除）；编辑成员（多选卡入组；反选/全选 + 确定）；列表「快速分组」Sheet（多选加入，可同时属多组）；删除分组 不删卡

  • 权益组合：新建默认 四类 Switch 全部关闭，按需开启配置；面值（金额与赠送；仅可用于支付不含面值的办卡/购卡、收费延期及项目消费；不可用于含面值办卡、不可购买价目产品）、项目（独立计次 / 关联计次 双模式：打开项目开关默认独立计次 = 只设次数 + 适用范围（=卡名只读），名义项目不进价目表，与面值/产品/折扣互斥（只能有独立计次一种权益 + 单一次数池）；关联计次 = 每项/共计、购买/赠送/不限次；每项拆成一项目一票）、产品（行内数量，一种产品一票，不可不限量）、折扣（比例/固定金额）；均可配置多张权益 ticket

  • 卡面主题色（5 色：蜜桃/薄荷/雾霾/香芋/奶茶，默认蜜桃）、卡有效期限（日/月/年/永久；含项目/产品/折扣时受期限约束；含不限次项目时不可为永久）

  • 用卡策略：消耗及退卡计算规则、业绩计算规则（含总权益面值明细）
  • 办卡：单选既存会员 → 「去结账」→ 确认办卡（应付可改、办卡日期、服务员工）→ 开单记账支付 → 支付成功回调入账 → 办卡成功
  • 已持卡：延期（免费立即写；收费须支付成功后再写；纯面值/模板永久 toast 无需延期）、整卡退卡（估值 + 实退可改；仅记账）
  • 上下架及文案提示
  • 旧入口全量替换（见完整稿 §1.6）

1.4 本期不做（Out）

  • 开单记账支付页 UI 全链路 — 不在本文展开；交接契约见完整稿 §7.7（未就绪时 toast「开单记账模块未就绪」）
  • 价目表作为独立产品交付 — 不在本文展开；规格见同目录 PRD-项目创建与管理.md。会员卡金额以 元 为准（完整稿 §7.8）
  • 会员管理（会员 CRUD；办卡仅从既存会员列表 单选）
  • 部分退卡、劳动业绩独立运算台、预约联调
  • 退卡资金原路退 / 退款渠道 — 本期不做
  • 原型工具栏「无数据/有数据」造数按钮 — 仅演示，不进正式产品

1.5 旧能力 ↔ 新组合权益（能力映射，不写废弃产品名）

旧体系常见能力（语义） 新体系如何配置
储值/充值类（买赠面值） 开启 面值：填面值金额；赠送 = 面值 − 购买金额（自动）；持卡面值 仅可支付不含面值的办卡/购卡、延期与项目消费；不可支付含面值新办卡，不可购价目产品
次卡/项目次数类 开启 项目：选适用项目；每项或共计；购买/赠送次数或不定次；保存后每项 = 一项目一 ticket
产品次数/礼品类 开启 产品：行内设数量（qty≥1 为已选）；一种产品一张 ticket；禁止不限量
折扣/会员价类 开启 折扣：选适用项目；标尺折扣或固定金额
期限卡 Step1 有效期限；含不限次项目时不可为「永久」；含项目/产品/折扣时须设妥期限
组合（储值+项目+折扣等） Step2 同时开启多类权益 并分别配置
旧类型无法覆盖的组合 任意权益开关组合 + 独立用卡策略

映射不足时 以新字段与原型行为为准，不编造旧系统字段表。

1.6 旧入口全量替换（摘要）

工作台 「卡管理」 / 会员卡管理 / 顾客详情 / 开单办卡 / 旧卡搜索详情 / 认领·AI 录卡：本期一律切新模板体系；历史旧类型卡只读兼容，不可新建旧类型。细则见完整稿 §1.6。

2.1 角色

角色 说明

店员 【待产品确认】 本期原型未表现差异；权限占位见完整稿

2.2 核心场景

场景 用户期望
首次建卡 三步填完保存 → 上架 → 可立即办卡
配置组合权益 面值/项目/产品/折扣按需勾选配置，预览卡面
分组运营 新建分组 → 编辑成员或快速分组 → 列表按组筛选；空组可「添加卡到本组」
有持卡后改规则 不能直接编辑模板；复制建卡后改新卡
停售 下架后新客不能办；已持卡不受影响
再开售 重新上架后可再办
为会员办卡 单选未持该卡的会员 → 「去结账」→ 确认办卡（改应付/办卡日期、选服务员工；演示默认还须选工位）→ 开单记账支付 → 办卡成功
延期 对有期限权益持卡设置延期时长；含折扣且参考费用 > 0 时走开单同款支付页，支付成功后再写延期；费用为 0 或选永久则立即生效；纯面值/模板永久仅 toast 无需延期
退卡 看到建议退款与明细，改实际退款后确认整卡退；结束持卡并记实退（不走支付退款通道）

2.3 成功标准（可判定）

  1. 空店可创建至少一张在售卡并出现在「在售」列表。
  2. Step2 至少有一类已配置有效内容的权益 才能进入 Step3 / 保存成功；开关已开但无内容时 自动关闭该开关（不拦截下一步；细则见完整稿）。
  3. 当前有效持卡 > 0 时详情「编辑」不可用，并提示复制建卡。
  4. 已下架卡列表无「办卡/退卡」入口；详情可「已持卡管理」（退卡/延期）。
  5. 支付成功办卡后，持卡人数/办卡次数等运营数据按规则增加；入账金额以确认办卡页应付为准。
  6. 退卡确认后该会员不再作为有效持卡；进入退卡成功页，实退金额以确认值为准展示。
  7. 有卡时列表展示分组筛选；空组筛选显示「本组暂无会员卡」并可进入编辑成员。

模块 4　公式与策略摘要

读者：前端 ✓ · 后端 必看 · 测试 ✓
算法以 demo.html 为准；逐步公式、明细行与完整算例见完整稿模块 8。

4.1 总权益面值（均值分母）

计入：面值 + 有限次项目权重（原价×次数；共计用组内均价×次数）+ 产品（原价×数量）。
不计入：折扣、不限次。

4.2 消耗及退卡

[ \text{建议退款} = \max(0,\ \text{办卡实付} - \text{消耗价值}) ]

策略 / 卡型 消耗要点
均值 · 纯折扣 实付 ×（已过天数 ÷ 总有效期）；永久按 1095 天；已享优惠不计入消耗
均值 · 组合 各项按权重分摊实付，再按已用次数/数量/面值折算消耗；折扣已省可另计行且不占实付份额
均值 · 仅不限次且分母为空 整笔实付按天摊销
减值 项目按原价×已用次数等累计；建议退款公式同上
独立计次 名义项目 = 适用范围（=卡名），不进价目表；开单扣次单价 = 实付 ÷ 总次数，按次扣减剩余；唯一权益 + 单一次数池（与面值/产品/折扣互斥）

实退可改；确认后仅结束持卡并记实退。

4.3 业绩

类型 摘要
卡模板 · 均值计绩 组合同分摊结构；纯折扣 = 项目折后价；不限次劳动按价目原价
卡模板 · 减值计绩 按价目原价口径（配置名「原价模式」）
办卡业绩 支付成功后按应付分摊到服务员工；平均分配 / 按工位（演示默认按工位）
独立计次 · 业绩/提成 业绩设置 → 办卡业绩 / 劳动业绩 / 按项提成 →「独立计次卡」分组；劳动业绩名义项目单价 = 实付 ÷ 总次数

4.4 延期费用（含折扣时）

[ \text{参考费用} = \mathrm{round}!\left(\text{模板购买金额} \times \frac{\text{延期天数}}{\text{原有效期天数}}\right) ]

可改为 ≥0；0 或选永久 → 立即写卡；>0 → 支付成功后再写。纯面值/模板永久：toast 无需延期。

4.5 速查算例

# 场景 期望方向
A 纯面值未消费 建议退 ≈ 实付
B 计次减值已用 2×50 消耗 ≈ 100
C 纯折扣永久均值 按已过/1095 摊销
F 买 900、延期 30/365、含折扣 默认参考费 = round(900×30/365)
G 独立计次：买 680 / 10 次 开单扣次单价 68/次；已用 4 → 剩 6 次
