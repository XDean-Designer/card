军阵 · 主帅与先锋

主帅（店主）调兵布阵、执掌全局；先锋（店员）前线接敌、完成收银。分工不是能力缺失，是阵法本应如此。

主帅 店主 · 全店最高权限

  • 开单 / 结算 / 查看流水
  • 查看与改动价目表、会员卡
  • 办卡、充值、续费续次、延期、退卡
  • 创建员工、经营配置与报表相关能力
  • 开单改价等完整经营动作

先锋 店员 · 前线作业权限

  • 开单 / 结算
  • 查看价目表、查看卡项
  • 办新卡、充值、续费/续次
  • 不改价目 / 不改会员卡模板
  • 不开单改价、不延期退卡、不创建员工、不看流水
配置与看数由主帅完成、前线收银由先锋完成——这是角色分工。原型另有合伙人 / 店长 / 高级店员等档位，本页讲解聚焦店主与店员。

权限矩阵来源：交互原型添加员工页「权限说明」弹窗。现网细权若有差异，以线上配置为准。

铸剑五炼

从好钢到绝世神兵

一柄绝世宝剑，必经选矿、熔炉、锻打、淬火、开刃五道工序。RTB 重构正是同一炉火。
铸剑的是我们，持剑的是老板——老板出剑，我们护剑。

已铸成
第一炼选矿 · 好钢已备
铸剑的前提是选对矿。现网六大战役、十场胜仗全部走通，证明经营场景这块矿，已经是好钢——不赌从零开始。
  • F 入驻就位：开店 + 价目卡券 + 客户员工录入，数据就位即可开工
  • A 到店预约：未预约、预约履约、改期取消均可闭环
  • B 员工人效：建档、权限、提成、排班口径、奖惩齐备
  • C 库存：可售卖 + 项目消耗两类货都可管理
  • D 经营看数：营收、客流、卡项、下钻与支出结余可查
  • E 前置与收银：价目卡券前置 + 划卡办卡收银闭环
已铸成
第二炼熔炉 · 融会贯通
千度熔炼，杂质成渣，铁骨合一。重构把各模块放进同一座熔炉，语义与数据不再各说各话。
  • 权益能力模型打通：价目（项目/产品）→ 会员卡权益组合 → 开单扣减/办卡，同一套能力语义
  • 演示数据同源：卡 / 价目 / 开单 / 员工 / 支出共用演示池，联调演示一致
  • 设计规范对齐：视觉与组件跟随剑琅联盟设计规范，手机框交付
  • 深链可测：FLOW 地图节点均可 ?flow= 直达，评审与截图直达
已铸成
第三炼锻打 · 铸骨成型
千锤百炼，剑骨成形。主链、支线、拦截态一炉成形，核心链路完整落地。
  • 价目表：项目/产品、分组拖拽、绑卡锁定、下架隐藏
  • 会员卡：三步建卡、权益组合、上下架、办卡、延期、退卡估值
  • 开单记账：选客→点单→结算→分账→成功，权益与打折同屏
  • 订单流水：退改、差价、尾款单、自助收银
  • 员工管理：职位权限、薪资提成、业绩奖惩，排班为下级子能力
  • 支出 / 库存：记支出流水；入出库、规格、调拨
  • 经营分析：门店 / 商城 / 自助报表与资金构成钻取
已铸成
第四炼淬火 · 刚而不脆
淬水定形，剑身既利且韧。重构把关键契约钉死，钱、卡、账在任何场景都不含糊。
  • 支付成功回调后才入账：办卡付款对齐开单结账契约，钱到才成单
  • 持卡数 > 0 锁定模板：关键字段不可误改，历史卡只读兼容、不可新建旧类型
  • 提成员工确认制：店主改数须填原因 → 待确认草稿 → 员工同意后才计入合计（可驳回）
  • 绑卡锁定防误改误删：价目与卡、开单联动处均有护栏
  • 价目变更拦截：分账前金额与价目不一致即阻断，确认后回到分账
淬刃在途
第五炼开刃 · 锋芒初现
磨砺开刃，锋芒毕现。利器再淬一把火，AI 与余下部件正在炉中。
  • AI 助手 · 存量数据快速准确导入（研发中）——降低上线与迁店成本，让数据就位更快
  • 待铸部件：客户管理、预约管理、优惠券管理、员工排班（当前为占位）
